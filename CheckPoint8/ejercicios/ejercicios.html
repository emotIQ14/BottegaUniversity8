Bucle for que imprime los nombres de la lista

Recorremos la lista ["velma", "exploradora", "jane", "john", "harry"] con un bucle for clásico, usando un índice numérico que arranca en 0 y se incrementa hasta llegar al final del array.

const miLista = ["velma", "exploradora", "jane", "john", "harry"]; for (let i = 0; i < miLista.length; i++) { console.log(miLista[i]); }
2

Bucle while que recorre la misma lista

Misma lista, pero ahora con un bucle while. La clave está en el contador: lo incrementamos en cada iteración para que la condición se vuelva falsa cuando termine la lista. Sin él, tendríamos un bucle infinito.

const miLista = ["velma", "exploradora", "jane", "john", "harry"]; let contador = 0; while (contador < miLista.length) { console.log(miLista[contador]); contador++; // evita el bucle infinito }
3

Función de flecha que devuelve "Hola mundo"

Una arrow function en su forma más concisa: sin parámetros, una sola expresión y retorno implícito (no necesita la palabra return ni llaves).

const saludar = () => "Hola mundo"; console.log(saludar());
